Project Overview
This repository houses a data analytics project focused on evaluating inventory health, stock distribution, and supplier reliability across a multi-warehouse supply chain network. Upon cleaning and analyzing 1,0001 product records spanning across 3 warehouses and 5 locations, this Excel and Power Query-driven analysis provides stakeholders with actionable insights to reduce stock-outs, optimize reorder timing, and identify underperforming suppliers.
The analysis provides both a macro-level overview of inventory value and stock status across all the 3 warehouses, and a micro-targeted evaluation of individual categories and suppliers to isolate operational risk points.
Tech Skills Demonstrated
Data Transformation & ETL: Power Query (Data cleaning, handling missing values, standardizing text and category naming, fixing inconsistent date and numeric formats)
Analytical Calculations: Excel formulas (Recalculated and validated Inventory Value, conditional Status logic, restock-recency tracking).
